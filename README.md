# PLT — Parietal Lobe Trainer

Тренажёр визуализации через сенсорное замещение «изображение → звук» (принцип The vOICe, P. B. L. Meijer; независимая реализация на Web Audio).

## Как опубликовать на GitHub Pages
1. Создайте репозиторий, например `plt`.
2. Загрузите в корень `index.html` (и этот README): **Add file → Upload files → Commit**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/plt/`.

На телефоне можно «Добавить на главный экран»: откроется как приложение на весь экран.

## Цикл тренировки
Уровень сложности → «Начать» → отсчёт (закрыть глаза) → N сканов фигуры звуком → двойной сигнал «откройте глаза» → сравнение и оценка (совпало / частично / нет) → «Далее».

## Кодирование
- Горизонталь = время, скан слева направо (по умолчанию 1 с).
- Вертикаль = высота тона, экспоненциально 500–5000 Гц (верх — высокий).
- Яркость = громкость. Стерео: звук смещается из левого уха в правое.
- Растр 64×64.

## Уровни
1 Линии · 2 Линии и углы · 3 Простые фигуры · 4 Простые фигуры+ (повороты, заливка) · 5 Многоугольники · 6 Искажённые фигуры · 7 Кривые · 8 Смешанные контуры · 9 Две фигуры · 10 Сцены (2–3 фигуры)

## Режим «Буквы и слова»
1 Простые буквы (Г, Т, П…) · 2 Буквы с диагоналями · 3 Округлые буквы · 4 Любая буква · 5 Две буквы · 6 Слова из 3 букв · 7 Из 4 букв · 8 Из 5 букв · 9 Из 6–7 букв · 10 Длинные слова (8–10 букв)

Окно растягивается по длине слова; скан по умолчанию удлиняется пропорционально, чтобы время на букву было постоянным. Есть вариант строчных букв.

Статистика хранится в localStorage браузера и выгружается в CSV (время, уровень, фигура, оценка, длительность скана, число повторов).
